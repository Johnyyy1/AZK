# PRD: Smart Irrigation Web App ("AquaSmart") ## 1. Project Overview A high-fidelity web application for managing smart irrigation systems, focusing on automation, real-time sensor data, and water conservation. ## 2. Aesthetic Direction: "Technical Organic" * **Tone**: Professional, reliable, data-driven, and eco-conscious. * **Typography**: * Display: A characterful, modern Sans-Serif (e.g., *Clash Display* or similar). * Body: A highly legible, technical Sans-Serif (e.g., *Satoshi* or *General Sans*). * **Color Palette**: * Primary: Deep Forest Green (#1A3C34) * Secondary: Vibrant Sprout Green (#4ADE80) * Accent: Water Blue (#3B82F6) * Background: Soft Off-White (#F8FAFC) or Dark Slate (#0F172A) for dashboard. * **Visual Elements**: Glassmorphism for cards, subtle noise textures, organic SVG patterns, and smooth micro-interactions. ## 3. Screen Inventory & Flow ### Phase 1: Public & Entry 1. **Landing Page**: Hero, Features, How it Works, Dashboard Preview, Benefits, Footer. 2. **Authentication**: Login, Register, Password Reset (minimalist, high-focus forms). ### Phase 2: Core Dashboard & Control 3. **Main Dashboard**: System status, Zone overview cards, Real-time sensor widgets, Quick actions. 4. **Manual Control**: Interactive zone map/list with toggle states and duration sliders. 5. **Scheduling & Automation**: Visual calendar/timeline for watering, conditional logic builder (If/Then rules). ### Phase 3: Management & Data 6. **Zones Management**: CRUD interface for irrigation zones with property configuration. 7. **Sensors & Devices**: Technical list view with connection status and diagnostic logs. 8. **History & Analytics**: Interactive charts for moisture, temp, and water usage trends. ### Phase 4: Utilities & Profile 9. **Notifications**: Categorized alert center (Low moisture, device offline). 10. **Weather Integration**: Local forecast cards with "Rain Skip" automation status. 11. **Settings & Profile**: Global units, timezones, notification preferences, and account security. 12. **Help & Documentation**: FAQ and setup guides. ## 4. Key Components (Shared) * **Navigation**: Sidebar for App, Top-nav for Landing. * **Status Indicators**: Pulse animations for active watering. * **Data Visualization**: Custom Sparklines and Gauge components. * **Forms**: Styled inputs with clear validation states.
